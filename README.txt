NOVACART — STORE PROTOTYPE

Files:
- index.html: responsive storefront prototype in English.

How to test:
1. Extract the ZIP.
2. Open index.html in a modern browser.
3. Test product buttons and demo cart.

Important:
- This is a front-end prototype, not a live store.
- Prices are illustrative and no supplier has been confirmed.
- Checkout, payment processing, shipping calculations, inventory sync, order fulfillment, legal pages, and customer data storage are not implemented.
- Do not accept real orders until supplier terms, product quality, shipping times, returns, taxes, privacy policy, and payment processing are configured and tested.
- To publish online, upload the files to a static host such as GitHub Pages or Cloudflare Pages. A real checkout requires an ecommerce/payment integration.
